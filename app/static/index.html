Documentación Académica del Proyecto Universitario

Fundamentos Técnicos y Metodología de Inteligencia de Precios

Explicación rigurosa sobre recolección automatizada, backend seguro, algoritmos de matching, ética y limitaciones técnicas.

1. ¿Qué es Web Scraping y para qué sirve?

El Web Scraping es la técnica computacional orientada a extraer datos de sitios web de manera programática y estructurada. En el comercio electrónico de moda, permite a una tienda monitorear la dinámica de precios, lanzamientos de colecciones y niveles de inventario de competidores líderes para ajustar sus propias estrategias comerciales con datos verídicos.

2. ¿Por qué es indispensable una arquitectura Backend?

Un navegador frontend no puede realizar scraping directo debido a las políticas de seguridad del mismo origen (CORS), expondría la lógica interna y credenciales, y no puede gestionar sesiones concurrentes ni reintentos. El backend en Python (FastAPI) centraliza las peticiones HTTP, respeta encabezados legítimos, parsea el DOM/JSON y almacena historiales en base de datos.

3. Flujo de Extracción y Adaptadores Modulares

PriceHunter implementa el patrón Adapter independiente para cada marca (UndergoldAdapter y ClementAdapter). Si una tienda modifica su estructura HTML o API interna, solo se actualiza su adaptador aislado sin afectar el resto de la plataforma ni la operatividad del otro competidor.

4. Algoritmo de Coincidencia (Fuzzy Matching)

Se aplica normalización léxica (eliminación de acentos diacríticos, mapeo de sinónimos urbanos: t-shirt = camiseta, oversized = holgada). La similitud se calcula mediante una combinación ponderada de Token Set Ratio (distancia de Levenshtein robusta al orden de palabras) y Jaccard Keyword Overlap, generando niveles de confianza transparentes (Alta, Media, Baja).

5. Integridad de Datos: En Vivo vs Demostración

La plataforma garantiza honestidad algorítmica estricta: nunca reemplaza de forma encubierta un fallo de conexión con datos ficticios. Cada registro indica explícitamente su procedencia (En Vivo, Demostración o Entrada Manual). Si un competidor falla, se informa el motivo exacto y se ofrece el enlace oficial.

6. Ética, robots.txt y Limitaciones Técnicas

PriceHunter no elude controles de acceso ni CAPTCHAs, respeta intervalos de petición razonables mediante timeouts y consultas acotadas. Las limitaciones del mundo real incluyen cambios en selectores CSS, protección anti-bot perimetral (Cloudflare) y divergencia en tallas o composición textil de cada fabricante.
